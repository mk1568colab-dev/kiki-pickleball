# Kiki Pickleball

## For Instructors

**[Visit the instructor website](https://mk1568colab-dev.github.io/kiki-pickleball/)**

Kiki Pickleball is an instructor-led classroom business simulation for
operations and supply chain management education. Teams manage competing
paddle firms and connect forecasting, sourcing, capacity, quality,
inventory, product development, and cash decisions.

The website includes:

- A tour of actual game screens from fictional practice classrooms.
- An adaptable preparation, first-session, and extended-play teaching sequence.
- A student quick start, instructor outline, and debrief questions.
- A classroom team estimate and downloadable introductory teaching outline.

Classroom access is arranged separately. Contact details will be added later.
This website does not provide game sign-ins or create accounts.

## Repository Scope

This repository contains only the public instructor website: static HTML,
CSS, browser interactions, reviewed demonstration images, and icon assets.
It is not the simulation application or an open-source release of its engine.
No game logic, database, account credentials, student records, classroom
backups, or operational deployment configuration are included.

Publishing this website does not deploy or change the hosted classroom game.
The site does not contact a game server or use analytics, cookies, or form
submissions. Classroom estimates stay in the visitor's browser.

## Materials

Screenshots show example data from isolated practice classrooms, not actual
student records. Introductory guides complement the current classroom
operating manuals; they do not replace them. Classroom pacing is adaptable.

The hero equipment image is AI-generated. The Kiki mascot is an existing
project asset. Icons are provided by Lucide; the third-party license is in
`assets/LUCIDE_LICENSE.txt`.
